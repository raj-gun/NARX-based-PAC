# NonSysID-i

This folder contains the stand-alone **NonSysID-i** routines required by the NARX-based PAC implementation in this repository.

NonSysID-i is the dedicated input-only variant of **NonSysID**, used here for identifying the input-only NARX models employed by the NARX-PAC method.

For the full NonSysID package, documentation, examples, and citation information, please see:

https://github.com/raj-gun/NonSysID
